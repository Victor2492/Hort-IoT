# Hort-IoT
Aquesta Situació d'Aprenentatge suposa l'evolució natural del projecte d'automatització de l'hort escolar cap a un sistema integrat d'Internet de les Coses (IoT). L'objectiu principal és que el sistema de reg no només actue de forma autònoma basant-se en sensors locals, sinó que siga capaç de recol·lectar, processar i transmetre dades en temps real
