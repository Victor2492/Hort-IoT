## 1. Presentació del projecte

### Què farem?

Dissenyarem i construirem **caixons de cultiu modulars** a partir de fusta reciclada (palets, mobles en desús, restes de fusteria). Cada grup construirà el seu propi caixó, que formarà part de l'**hort escolar** del centre.

### Per què és important?

```
Problema real → Solució tecnològica → Impacte al centre
```

- ♻️ **Economia circular**: fusta que anava al contenidor es converteix en un producte útil
- 🌱 **Hort escolar**: els caixons seran la base física on creixeran les plantes
- 🤖 **Connexió tecnològica**: cada caixó estarà preparat per a sensors d'humitat i reg automàtic
- 💶 **Cost de la fusta**: **0 €** (material totalment reciclat)

### Connexió amb altres SA

```
SA2: Caixons de fusta  →  SA3: Reixes de drenatge 3D  →  SA5 i SA6: Automatització (Arduino/ESP32)
       
```

#### 5.2 La fusta reciclada: com triar bé

> 🚨 **Criteri més important**: el marcatge del palet

| Material | Apte per a hort? | Com identificar-lo |
|----------|:---:|---|
| Palet marcat **HT** (Heat Treated) | ✅ **SÍ** | Logo IPPC + lletres HT gravades a la fusta |
| Palet marcat **MB** (Methyl Bromide) | ❌ **NO** | Lletres MB = pesticide tòxic → **DESCARTAR** |
| Fusta massissa de mobles | ✅ **SÍ** | Sense color verd, llimar 1a capa |
| **MDF / Aglomerat** | ❌ **NO** | Es dissol amb humitat, allibera formaldehid |
| Fusta verdosa (CCA) | ❌ **NO** | Color verd = arsènic + coure → **PERILLÓS** |
| Canyes / bambú | ⚠️ **Parcial** | Per a reforços, no per a parets principals |

#### 5.3 El teu plànol tècnic acotat

Abans de construir, **has de dibuixar el plànol** del teu caixó a mà alçada. El plànol és el teu "contracte" amb tu mateix/a.

**El plànol ha de tenir:**

- [ ] Vista en planta (des de dalt)
- [ ] Alçat (vista frontal)
- [ ] Perfil (vista lateral)
- [ ] Totes les cotes en mm
- [ ] Escala indicada (recomanada: 1:5)
- [ ] Rètol amb nom, grup i data

**Dimensions estàndard recomanades:**

```
Longitud:  80–120 cm   (transportable per 2 persones)

Alçada:    25–35 cm    (suficient per a arrels curtes)
```

## 7. Fase 3 – Construcció del caixó

### Sessions S4–S8 | Durada: 5 × 55 min

Segueix el procés en ordre. **Marca cada pas quan l'hagis completat.**

#### Pas 1 – Desmuntatge de palets

- [ ] Verificar marcatge HT (descartar MB, MDF, fusta verdosa)
- [ ] Inserir peu de cabra entre llistó i bloc; cops suaus i progressius
- [ ] Extreure tots els claus i grapes amb tenalles
- [ ] Classificar peces: B / R / D

#### Pas 2 – Llimat i tractament

- [ ] Llimar amb paper G80 (rugositats grans) en la **direcció de la fibra**
- [ ] Acabat final amb paper G120
- [ ] Aplicar oli de llinosa cru (drap o brotxa). Deixar 24 h entre capes
- [ ] ⚠️ **Mascareta FFP2 obligatòria durant el llimat**

#### Pas 3 – Mesura, marcat i forats passacables

> 📐 **Regla d'or: mesura 2 vegades, talla 1 vegada**

- [ ] Traslladar cotes del plànol a la fusta amb cinta mètrica + esquadra
- [ ] Marcar els **forats passacables ABANS de muntar**:
  - `Ø22 mm` al costat curt, 5 cm de la base → *sensor d'humitat*
  - `Ø22 mm` al costat llarg, 5 cm del cantell → *cablejat elèctric*
  - `Ø12 mm` al costat curt, 8 cm del cantell → *entrada tub de reg*

#### Pas 4 – Tall de peces

```
⛔ Serradora circular → DOCENT
✅ Serra de mà       → Alumnat (peça fixada amb mordassa)
```

- [ ] Verificar dimensions de cada peça just després del tall

#### Pas 5 – Muntatge laterals

- [ ] Pre-forar punts d'unió amb Ø3 mm (evita que la fusta es fenda)
- [ ] Cargolar 4 laterals amb cargols galvanitzats 4,5×45 mm
- [ ] Col·locar **8 angles metàl·lics** als cantons interiors
- [ ] Verificar quadratura: les 2 **diagonals han de ser iguals ±2 mm**

#### Pas 6 – Base i potes

- [ ] Base: llistons amb **1–1,5 cm de separació** (per al drenatge)
- [ ] Potes: 4 llistons 5×5 cm als cantons, **12 cm d'alçada**
- [ ] Verificar horitzontalitat amb nivell de bombolla

#### Pas 7 – Passacables i drenatge

- [ ] Introduir tubs PVC Ø20 mm als forats passacables + taps de goma
- [ ] Capa de **3–5 cm de graveta volcànica** al fons
- [ ] Cobrir interior amb **geotèxtil anti-arrels** (fons + parets). Fixar amb grapadora
- [ ] Mescla substrat: **60% terra + 20% perlita + 20% compost**
- [ ] Omplir fins a **5 cm del cantell** (marge per a regar)

## 8. Fase 4 – Integració tecnològica

### Sessions S9–S10 | Connexió amb la SA d'automatització

Un cop construït el caixó, és el moment d'instal·lar la tecnologia. Els passacables que has fet serviran per a:

#### Components a instal·lar

| Component | On es col·loca | Funció |
|-----------|---------------|--------|
| Sensor capacitiu d'humitat v1.2 | Passacables costat curt | Mesura la humitat del substrat |
| Tub de reg per degoteig (Ø4 mm) | Entrada reg costat curt | Distribuir l'aigua uniformement |
| Cables d'alimentació i dades | Passacables costat llarg | Connectar sensor a Arduino/ESP32 |

#### Exemple de codi Arduino (reg automàtic)

```cpp
const int sensorPin = A0;   // Pin del sensor capacitiu d'humitat
const int bombaPin  = 7;    // Pin de control de la bomba de reg
const int LLINDAR   = 650;  // Valor en sec (0 = mullat, 1023 = sec)

void loop() {
  int humitat = analogRead(sensorPin);
  Serial.println("Humitat: " + String(humitat));

  if (humitat > LLINDAR) {          // Si el sòl és sec...
    digitalWrite(bombaPin, HIGH);   // Activar bomba
    delay(5000);                    // Regar 5 segons
    digitalWrite(bombaPin, LOW);    // Apagar bomba
  }
  delay(60000); // Comprovar cada minut
}
```

> 💡 El codi complet d'automatització forma part de la SA4 (Arduino/ESP32). Aquí només provem el funcionament manual.

## 9. Fase 5 – Compost (Biologia)

### Sessió S11 | Sessió interdisciplinar amb Biologia / CCNN

#### El compostador escolar

Construïm un compostador amb fusta sobrant del projecte per a produir el nostre propi compost.

#### ✅ SÍ – Residus vàlids

- 🟢 **Materials verds** (rics en nitrogen): restes de fruita i verdura, posos de cafè, restes de plantes
- 🟤 **Materials marrons** (rics en carboni): cartó trossejat, paper, serradures del taller, fulles seques

#### ❌ NO – Prohibit compostar

- Carns, peixos i productes làctics
- Olis i greixos
- Restes amb pesticides
- Fusta tractada (CCA, MB, vernís)

#### El cicle del compost

```
Residus orgànics → Microorganismes → Descomposició (calor) → Compost madur → Substrat del caixó
      ↑                                                                              |
      └──────────────────────── Les plantes tornen nutrients ──────────────────────┘
```

**Temps**: 3–6 mesos | **Proporció**: 1 part verda + 3 parts marró | **Humitat**: 50–60%
